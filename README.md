# Fashion Sales Dashboard

## Project Overview

This project presents an interactive Fashion Sales Dashboard developed in Power BI to analyze sales performance, customer behavior, product category performance, brand contribution, and return trends. The dashboard helps identify key business insights and supports data-driven decision-making through interactive visualizations and KPIs.

---

## Objectives

- Analyze overall sales performance and revenue trends.
- Identify top-performing product categories and brands.
- Monitor customer behavior and spending patterns.
- Evaluate product return rates.
- Provide interactive insights through dashboards.

---

## Tools & Technologies

- Power BI
- Excel
- DAX
- Power Query
- Data Visualization
- Exploratory Data Analysis (EDA)

---

## Dataset Information

The dataset contains fashion retail sales information, including:

- Customer Details
- Product Categories
- Brands
- Order Information
- Revenue
- Ratings
- Return Status
- Monthly Sales Data

---

## Exploratory Data Analysis (EDA)

Before building the dashboard, exploratory data analysis was performed to understand the dataset and identify meaningful patterns.

### EDA Tasks Performed

- Data Cleaning and Transformation
- Missing Value Analysis
- Duplicate Record Checking
- Category-wise Revenue Analysis
- Brand Performance Analysis
- Customer Behavior Analysis
- Return Rate Analysis
- Monthly Sales Trend Analysis

### Key Findings

- Outerwear generated the highest revenue among all categories.
- Return rate was approximately 14.71%.
- A small group of customers contributed significantly to revenue.
- Brand performance varied across categories.
- Sales trends showed fluctuations throughout the year.

- Generated total revenue of approximately $186K.
- Processed 587 customer orders.
- Identified top-spending customers and their purchasing behavior.
- Outerwear and Shoes were the highest revenue-generating categories.
- Return rates varied across product categories.
- Brand-wise revenue analysis highlighted major contributors to overall sales.
